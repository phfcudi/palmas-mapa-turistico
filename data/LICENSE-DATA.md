# Licença dos dados (pasta `data/`)

O código do projeto é MIT (ver `../LICENSE`). Os **dados** abaixo têm origem e licenças diferentes.

## Dados do OpenStreetMap — ODbL 1.0
* `raw/osm/*.geojson` — exportações do Overpass Turbo.
* `processed/*.json`, `processed/*.npy` — bases **derivadas** desses dados (regiões, vias, polígonos, calibração).

© colaboradores do OpenStreetMap — https://www.openstreetmap.org/copyright
Licença: Open Database License (ODbL) 1.0 — https://opendatacommons.org/licenses/odbl/1-0/

Pela ODbL, quem usa ou redistribui essa base deve **atribuir** o OpenStreetMap e, se redistribuir uma
base derivada, mantê-la sob a mesma licença (*share-alike*). A página gerada já exibe o crédito
“Base cartográfica © colaboradores do OpenStreetMap” no rodapé do painel; mantenha-o.

## Imagens-base — `base/tiles/*.png`
Capturas do mapa padrão do OpenStreetMap. Os dados são ODbL; a cartografia (estilo visual) do mapa padrão
é publicada pelo OSM sob CC BY-SA 2.0. Respeite a política de uso de tiles do OSM
(https://operations.osmfoundation.org/policies/tiles/) e mantenha a atribuição.

## Contribuições originais deste projeto
Contornos traçados à mão, posições estimadas de pontos turísticos e textos descritivos foram escritos
para este projeto. Os textos descritivos que citam o mapa turístico de Palmas trazem fatos (distâncias,
dimensões, nomes) com a fonte indicada; as fotos e o logotipo desse material **não** foram copiados.
Recomenda-se publicar essas contribuições sob **ODbL** (por serem parte da base derivada) ou
**CC BY-SA 4.0** — defina antes da primeira publicação.
